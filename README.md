| **SADPAC** | Chat with your own documents: a RAG app running fully local | LangChain, ChromaDB, Ollama, Streamlit |
| [**CNN Digit Recognition**](https://github.com/ChristianJakubzig/cnn-digit-recognition-project) | A convolutional neural network that recognizes handwritten digits, built step by step | PyTorch, MNIST, uv |
